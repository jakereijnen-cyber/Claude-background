# helper-desk

See what Claude and its helpers are doing at a glance.

- **Task bar:** a purple bar above the prompt fills as Claude ticks off its to-do list. It shows how many tasks are done and the one in progress. It appears only while Claude keeps a to-do list, and clears at your next request once every task is done.
- **Helper Desk panel:** a side panel with one live card per subagent: what it is working on, its current step, a progress bar, its tool calls ("steps"), its tokens and its running time. The panel opens by itself when the first subagent starts, and `/helper-desk` opens it any time. The 12 most recent helpers are kept, finished ones dimmed.

Works in Claude Code in the terminal, editors and the desktop app.
