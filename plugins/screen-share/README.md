# screen-share

Type `/screen-share` and every name, email address, phone number and money amount on screen turns into a grey bar (▇▇▇▇). Claude still reads the real data, so you can record or share your screen safely. Type `/screen-share` again, or press **Turn off** in the reminder above the prompt, to show everything again.

- **What is hidden:** your messages, Claude's replies, tool calls and their results (commands, file contents, search results), command output and Claude's questions.
- **How:** emails, phone numbers and amounts (€, $, £, EUR, USD...) are found by pattern, at once. People's names are found by a small, cheap model call within a couple of seconds of first showing, and from then on are hidden everywhere, first and last names alone too.
- **What is not hidden:** the text you are typing in the prompt box, other mods' panels, and anything outside Claude Code. A name can show for a moment before it is recognised, so turn the mode on before you start sharing.

Only the drawing changes: the stored chat and what Claude reads keep the real data. Works in Claude Code in the terminal, editors and the desktop and mobile apps.
